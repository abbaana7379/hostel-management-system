# Hostel Management System

This is a hostel management portal built with HTML, CSS, and JavaScript.

## Included features
- Admin panel
- Student panel
- Student registration
- Room allocation
- Occupancy tracking
- Fee management
- Complaint system
- Visitor log
- Monthly hostel reports

## Run the app
Open `index.html` directly in your browser.

If you want to serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — app layout
- `style.css` — styling and responsiveness
- `script.js` — app logic and data storage
